Essential Questions for AP CSA

  • How can objects and classes make problem solving easier and more efficient?
    • Objects and classes can represent real world items. These objects can be programmed to interact with each other in a way that resembles the real world. This allows programmers to approach problems in a systematic and more complex way.
  • What is a function, and how does it differ in a programming context than in a traditional mathematical setting?
    • Programming functions represent a few set lines of code that are executed whenever the function is invoked. While mathematical functions only execute mathematical operations, programming functions execute code.
  • What is the value of a function calling another function and how is this accomplished?
    • A function is called by writing the name of the function followed by parentheses: functionName(). This can be done inside another function. This can be used to break a long function into several managable parts.
  • What is the advantages of using arrays and array lists?
    • Arrays and array lists store data in a sequence. Without arrays, each data point would need a separate name with no way to group all of them.
  • What roles do member functions, private data members, and constructors play in a program containing classes?
    • Functions, private data members, and constructors describe the characteristics and behavior of a class. Functions can be thought of as actions that an instance of a class can take. Private data members store data that are required for a class to function properly, but are not always required by the user. Constructors are a special type of function that specifies what a new ly created object will do upon creation.
